# bleatsirc

**The house IRC client** — multiserver in the mIRC pattern, scriptable in
every language through an event bridge, reachable by CLI, SSH, or telnet
from a Termux screen, with the session drawn in the terminal.

bleatsirc is the **client**. The daemon is a separate project
(**bleats-ircd**): a custom Bahamut × UnrealIRCd hybrid with nick,
channel, and IRCop services embedded. Specifications for both live in
[`docs/`](docs/).

## The founding reference

[`docs/RFC1459-TEACHERS-REVISION-MAGVS.md`](docs/RFC1459-TEACHERS-REVISION-MAGVS.md)
— a Teacher's Revision (MAGVS) of RFC 1459 deep-diving every numeric and
every event: the RFC's text, annotated wire traces, the full six
inquiries per entry, and the house hookups to this client and the daemon.
Built brick by brick; each finished brick is pushed as it lands. The PDF
joins this docs area when the book is complete.
